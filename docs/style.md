# Style

How the app looks. What each part contains is in `docs/app-flow.md`; this file is how it is arranged on screen.

## Navbar

- **Desktop:** one row, left to right: logo, search bar, Add Pattern, profile icon that opens the dropdown.
- **Mobile:** the bar keeps the logo and the profile icon. The search bar and Add Pattern move behind a hamburger icon, which opens a `sheet` from the side.

## Colors

Soft purple and yellow. The values are in `app/globals.css`: `:root` for light, `.dark` for dark.
